# 方塊脫逃 Block Escape

一款 3D 解謎小遊戲：立方體表面布滿彎折的直角箭頭，點一下箭頭，它會沿著箭頭方向整條滑出；前方被別的箭頭擋住就出不去。把所有箭頭清空就過關，越快完成星星越多。

## 怎麼玩

- **點擊箭頭**：讓它滑出方塊
- **拖曳**：旋轉方塊（電腦也可用方向鍵）
- **雙指／滾輪**：縮放
- **提示**：亮出一支可以滑出的箭頭（+5 秒）
- 點錯一次 +2 秒；依總時間得到 1～3 顆星
- 進度與每關最佳成績會存在瀏覽器裡，可從關卡選單重玩刷星

關卡由程式產生，保證每一關都有解，關卡數無上限。

## 離線遊玩

下載 `block-escape.html`，用瀏覽器打開即可，不需網路。

## 開發

原始碼在 `src/`（`level.js` 關卡產生、`game.js` 遊戲與畫面、`template.html` 介面）。修改後執行：

```bash
node build.js
```

會把 Three.js（`vendor/three.min.js`，MIT 授權）與原始碼內嵌成單一的 `block-escape.html` 與 `index.html`。
